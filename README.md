# Agent 知识库 · AI 与大模型学习工作台

一套按「**你到哪一档**」组织起来的 Agent / 大模型知识站。纯静态单页，无构建、无依赖、无后端。

**在线访问：<https://zzt0818.github.io/ai-knowledge-workbench/>**

---

## 它解决什么问题

从「第一次听说 AI」到「自己做模型层的事」中间隔得挺远，一口气全塞给人只会劝退。
所以这里按使用者的实际处境分成五档（入门 / 认识 / 上手 / 搭建 / 开发），
每往前一档，多出来的不是更难的知识，而是**更靠后的问题**。

选一档，超出这一档的内容自动收起来；点「全部」随时摊开。
检索（<kbd>Ctrl</kbd> + <kbd>K</kbd>）始终跨全档，命中被收起的条目会自动切档并定位。

| 图谱 | 知识点之间的关联：谁垫在谁下面、怎么一条条走通 |

assets/

## 本地打开

直接双击 `index.html` 即可，`file://` 下所有功能可用（含检索、路由、动效）。
不需要起服务、不需要联网。

## 更新方式

内容都在 `assets/js/` 下的数据文件里，改完刷新页面就能看到。
托管端不发 `Cache-Control`，浏览器会启发式缓存静态资源，
所以发布前要换掉 `index.html` 里的资源版本串（`?v=…`），否则访客可能还看到旧脚本：

```
python _dev/bump_ver.py        # 打上当前时间戳
```

`_dev/` 是本地开发工具（自检、截图、探针、数据生成脚本），不进仓库也不影响站点运行。
